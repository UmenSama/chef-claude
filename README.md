# 👨‍🍳 ChefClaude

ChefClaude is an AI-powered recipe assistant that suggests recipes based on ingredients you have. Built with React and powered by LLMs like Mistral and Claude, it makes cooking with whatever's in your kitchen easier and more fun.

---

## 🚀 Features

- 🥗 **AI-generated recipes** based on user-provided ingredients
- 🧠 Integration with HuggingFace (Mixtral) and Anthropic (Claude)
- ✍️ Clean Markdown recipe rendering
- ⚛️ Built with React and Vite
- 🌱 Add your own ingredients to get dynamic suggestions
